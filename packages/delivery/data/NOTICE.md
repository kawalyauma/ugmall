`uganda-locations.json.gz` — Uganda's districts, sub-counties/divisions, parishes and
villages, built with `scripts/build-uganda-locations.py` from
[kusaasira/uganda-geo-data](https://github.com/kusaasira/uganda-geo-data)
(MIT License, Copyright (c) 2022 Joshua Kusaasira; data sourced from Uganda's
passport portal). Region grouping (Central/Eastern/Northern/Western) added by this project.

Areas missing from the official list (new estates, popular neighbourhood names) can
be added in Admin → Deliveries → Areas; they are stored as custom areas.
